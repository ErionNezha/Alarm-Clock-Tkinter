# ⏰ Alarm Clock

Orë alarmi me ndërfaqe grafike — zgjidh orën, minutat dhe sekondat dhe alarmi bie në kohën e caktuar. Ndërtuar me Tkinter (Python).

## 🚀 Si ta hapësh

Hap `index.html` — tab-i **Live Demo** ekzekutohet direkt në browser, ndërsa tab-i **Kodi Burim** tregon kodin e plotë.
